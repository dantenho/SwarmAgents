# SwarmAgents

Python repository for SwarmAgents — agents and examples.

Supported environments
- Python: 3.15
- Node.js: 26.11.1
- Ruff: 1.99

Quick start

1. Create and activate a virtual environment (recommended):

   python -m venv .venv
   source .venv/bin/activate

2. Install dependencies (if a requirements.txt or packaging config is present):

   pip install -r requirements.txt

3. Run lint and tests:

   ruff .
   pytest
